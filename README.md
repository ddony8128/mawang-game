# 마(피아)왕 게임

오프라인에서 모여 플레이하는
**실시간 소셜 마피아 게임을 진행하기 위한 웹 보조 시스템**

---

## 📌 프로젝트 개요

**마(피아)왕 게임**은
오프라인에서 사람들이 실제로 한 공간에 모여 대화하며 플레이하는 것을 전제로 설계된
**실시간 소셜 마피아 게임**입니다.

본 레포지토리는 게임 그 자체를 온라인으로 즐기기 위한 것이 아니라,
👉 **게임 진행을 안정적이고 공정하게 보조해주는 웹페이지 구현**을 목표로 합니다.

* 플레이어: 오프라인에서 직접 대화하며 추리
* 웹페이지:

  * 역할/카드/능력 처리
  * 타이머 관리
  * 공개/비공개 정보 분리
  * 룰 강제 및 실수 방지 UX 제공

---

## 🎮 핵심 컨셉

* **GM 없이도 모든 인원이 플레이어로 참여 가능**

  * 기본 모드에서는 자동 역할 배정 + 고정 룰로 즉시 플레이
* **GM(방장) 모드 지원**

  * 방장의 판단 하에:

    * 역할을 직접 배정
    * 카드/쿨타임/팀 구성 등 룰 수정
    * 판 단위 밸런스 조절 가능

## ❤️ 공통 게임 시스템

### 생명력 (HP)

* 모든 플레이어 기본 HP **3**
* HP 0 → 즉시 사망
* 사망 시:

  * 카드 획득 불가
  * 카드/능력/행동 불가
* **모든 플레이어의 현재 HP는 공개 정보**

---

### 🃏 카드 시스템

#### 카드 획득

* 게임 시작 시 카드 1장
* 이후 **3분마다 카드 1장**
* 카드 풀에서 **25% 확률로 4종 중 1장**

#### 카드 종류

| 카드  | 효과                       |
| --- | ------------------------ |
| 돋보기 | 2장: 팀 확인 / 3장: 정확한 역할 확인 |
| 칼   | 대상 1명에게 1 데미지            |
| 폭탄  | 대상 지정 → 5분 후 2 데미지       |
| 맥주  | 자기 자신 HP 1 회복            |

#### 손패 제한

* 최대 4장
* 초과 시 **강제 카드 버리기 모달**
* 정리 전까지 다른 행동 불가

---

### ⏱ 실시간 액션

* 언제든지 가능:

  * 카드 사용
  * 카드 양도
  * 역할 능력 사용
* 일부 능력은 **쿨타임 / 1회 제한**

## 🧑‍🤝‍🧑 역할 구성

### 악 팀

#### 마왕 – 공포의 마왕

* 사망 시 HP 3으로 1회 부활 (정체 공개)
* 겁주기: 대상 1명 1분간 행동 불가 (쿨 3분)

#### 마왕 – 분탕의 마왕

* 사망 후 3분간 생존
* 돋보기 대상 시 보일 역할을 지정 가능

---

### 배신자

#### 참모

* 시작 시 마왕 정체 인지
* 이번 판에 포함된 용사 역할 정보 인지

#### 타락자

* 시작 시 마왕 정체 인지
* 대상의 다음 카드 드로우를 맥주로 고정

---

### 선 팀 (용사)

| 역할   | 능력               |
| ---- | ---------------- |
| 패링맨  | 1분간 피해 무효        |
| 슬레이어 | 1회 3 데미지 공격 (공개) |
| 현자   | 돋보기 추가 획득        |
| 힐러   | HP 1 회복          |

---

### 시민

| 역할   | 특징                  |
| ---- | ------------------- |
| 약골   | HP 2 시작, HP 표시 왜곡   |
| 겁쟁이  | 카드 사용 50% 실패        |
| 정신병자 | 스스로를 용사로 인식 (능력 없음) |
| 실험체  | 사망 시 악 팀 카드 보너스     |

## ⚙️ 방장(GM) 설정

본 게임은 **플레이어가 직접 밸런스를 조절하도록 설계**되었습니다.

* 카드 드로우 주기 / 폭탄 시한 / 손패 제한 조정
* 마왕 부활 HP / 집념 시간 설정
* 팀 구성 직접 지정
* **GM 모드**:

  * 방장이 역할을 직접 배정 (중복 불가)
